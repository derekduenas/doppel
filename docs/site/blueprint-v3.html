Architecture

Two planes, one sealed crossing

Sensors write one append-only tape. The research plane turns it into exact P&L, mechanisms, fair value, flow intelligence and genomes, which a replay twin scores. Only a sealed genome crosses into execution, where riskd, the only key holder, sends Polymarket US quotes and Kalshi hedges. Full diagram: DOPPEL Architecture.

Python (batch)Research planeLedger, census, dossiers, flow, fair value, extraction, registry, twin. Correctness matters more than speed here.
Rust (ms)Hot pathRecorder first (being built, shadow run, then cutover), then fast fair, then runtime, riskd and gateways, ported from Edge-engine and pmus-execution.
HostingApex now, AWS laterKalshi's trading API is in AWS us-east-2. Polymarket US is about 33 ms from New York. The execution box goes nearest the venues once a genome earns it.
